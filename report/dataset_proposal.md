# Dataset proposal

The dataset proposal is in `report/REPORT.md`, section 7.5, subsection "Data opportunity": the dataset (five
components per sample, seed and scale, quality), why this data, how it targets each of the four failure categories,
three uses, the pilot and its acceptance test, the per-model targets, and the worked example. The submission page
(`site/`, section "Data opportunity") presents the same proposal.

Quality rule of the proposal: built by domain experts. A second expert reviews each checklist. Every check passes on the expert
deliverable. Each deficient variant fails the checks for the item it removes and passes the rest. Where a check and the
expert disagree, a reviewer decides before the sample is accepted.

The earlier version of this file (commit `0fcc9b5`) proposed the contents of a verified task package from the GDPval
v2 material checks; those material findings are reported in `report/REPORT.md` section 6.3 and
`docs/expert_gold_fail_audit.md`.
